# Agent instructions

Slack bot that replies once, in the thread, to Service Desk tickets still missing a category after a threshold. One Python file, one container. Docs index: [docs/README.md](docs/README.md).

## Commands

```bash
make venv     # .venv with the hash-locked dependency, pytest and ruff
make check    # the gate: ruff, pytest, tools/gen_diagram.py --check, tools/brand/check-icon.sh
make test     # pytest only (Slack is mocked)
make lint     # ruff only
make diagram  # redraw docs/assets/*.svg after changing tools/gen_diagram.py
docker compose up -d --build   # run it (needs a .env copied from .env.example)
```

Run `make check` before and after every change; CI runs the same gate.

## Layout

- `src/main.py`: configuration, the check loop and the heartbeat
- `tests/`: pytest suite
- `tools/`: diagram and brand generators; `docs/`: guides
- `Dockerfile`, `docker-compose.yml`: the container; the image copies only `src/` and the lock file
- `requirements.txt` (top level) and `requirements.lock.txt` (hashes, used by Docker and CI)

## Conventions

- Commits are conventional (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`) and authored by the repo owner. No co-author trailers, session ids or "generated by" lines in commits, PRs, issues or comments.
- Documentation must be true of the code: verify every command, flag and number, and keep no hand-typed counts that can drift.
- Never force-push `main`. Never commit secrets, tokens, channel or bot IDs, IP addresses, private hostnames or personal e-mail. The one public contact address is the one already in SECURITY.md.
- Python `snake_case`, directories `lowercase-kebab`, docs `docs/lowercase-kebab.md`.
- Diagrams are drawn by `tools/gen_diagram.py`; edit the generator, not the SVGs.
- `.env.example` lists every variable `src/main.py` reads; keep them in step.

## Do not change (runtime identifiers)

Environment variables (`SLACK_BOT_TOKEN`, `CHANNEL_ID`, `HELPDESK_BOT_ID`, `AGE_THRESHOLD_SECONDS`, `CHECK_INTERVAL_HOURS`, `REMINDER_LOG_FILE`, `REMINDER_MESSAGE`, `HEARTBEAT_FILE`); the heartbeat path `/tmp/itsd-reminder.heartbeat` read by both health checks; the reminder log format; the container name `itsd-reminder-bot` and image name `itsd-reminder`.
